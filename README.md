# JavaScript Notes and Practice
## Topics covered

-   Variables, data types, operators, input/output
-   Conditions, loops, functions, strings, and arrays
-   Spread/rest syntax, callbacks, and array methods
-   Objects, classes, inheritance, getters/setters, and destructuring
-   Dates, timers, closures, and DOM manipulation
-   Events, modules, error handling, Promises, and `async`/`await`
-   JSON and the Fetch API
-   Mini-project ideas for hands-on practice

## Notes

Read the detailed notes here:

## How to practise

1.  Read a topic's definition and example.
2.  Type the example yourself instead of only copying it.
3.  Run console examples in the browser developer console.
4.  For DOM examples, create an HTML file with the elements shown in the
    notes.
5.  Modify the examples and try the mini-projects.
